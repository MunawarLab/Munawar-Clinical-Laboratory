PUBLISH FREE WITH GITHUB PAGES
------------------------------
1. Sign in or create an account at https://github.com
2. Create a new public repository. A suitable name is:
   munawar-clinical-laboratory
3. Upload index.html, style.css, script.js, and details.text
   (you may also upload this README.txt).
4. Open the repository's Settings.
5. Select Pages from the left-side menu.
6. Under "Build and deployment", choose "Deploy from a branch".
7. Select the main branch and the /(root) folder, then Save.
8. Wait a few minutes. GitHub will show your published website address
   in the Pages section. It will usually look like:
   https://YOUR-USERNAME.github.io/munawar-clinical-laboratory/
